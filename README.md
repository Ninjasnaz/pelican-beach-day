# Pelican Beach Day

An interactive three.js beach scene. A cartoon pelican rides his bike around a winding boardwalk loop while beachgoers, vendors, and shops fill the shore. Fly around and explore, or follow the pelican.

**Controls (desktop):** W/S forward and back, A/D side to side, Q/E down and up, Shift to go faster, drag to look around, scroll to zoom, F to follow the pelican, Esc to fly free.
**Phones and tablets:** the camera follows the pelican automatically.

```bash
npm install
npm run dev
```

Built with three.js and Vite. Everything in the scene is made in code: no downloaded models or textures.
